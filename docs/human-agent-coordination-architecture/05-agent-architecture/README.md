# Arquitetura dos agentes

## Pergunta central

O que é um agente e como ele funciona?

## Inclui

- Diferenças entre modelo, habilidade, papel, agente, execução e sessão.
- Identidade, responsabilidade e objetivos do agente.
- Coordenadores, especialistas, executores, routers e auditores.
- Ativação por evento, prazo, rotina ou chamada humana.
- Ferramentas, capacidades e contexto recebido.
- Criação, suspensão, retomada e encerramento de agentes.

## Não inclui

- Definir a topologia completa das equipes.
- Definir o conteúdo e as regras da memória compartilhada.
- Definir a taxonomia geral dos objetos de trabalho.

## Artefatos esperados

Modelo conceitual do agente, variantes arquiteturais, critérios para criar outro agente e ciclos de execução.
