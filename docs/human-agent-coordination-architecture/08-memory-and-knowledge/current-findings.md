# Descobertas atuais: memória e conhecimento

## Camadas de memória

```text
conhecimento global de Marcus
→ contexto pessoal ou empresarial
→ memória da área ou programa
→ memória do projeto ou caso
→ memória do fio
→ contexto temporário da ação
```

Um agente recebe somente a parte necessária e permitida para sua responsabilidade.

## Formas de compartilhamento

- Memória isolada.
- Conhecimento herdado do nível superior.
- Resultado resumido para o nível superior.
- Consulta sob demanda.
- Base compartilhada entre projetos.
- Informação restrita a pessoa, equipe ou organização.

Regras e contexto descem; resultados e aprendizados sobem.

## Estado das informações

| Estado | Significado |
|---|---|
| Desconhecida | Ainda não existe valor conhecido |
| Conhecida, não verificada | Existe valor, mas falta confirmação |
| Conhecida e verificada | Pode apoiar uma decisão |
| Inferida | Foi deduzida e pode exigir confirmação |
| Desatualizada | Existiu, mas pode ter perdido validade |
| Conflitante | Existem valores incompatíveis |
| Indisponível | Não há fonte capaz de fornecê-la |
| Restrita | Existe, mas o acesso ou compartilhamento é limitado |

Uma informação pronta para uso pode exigir:

```text
conhecida && verificada && atual && permitida
```

## Proveniência necessária

Cada informação relevante pode registrar valor, origem, confiança, data, validade, sensibilidade e permissão de compartilhamento.

## Fronteiras já reconhecidas

- Pessoal e empresarial permanecem separados na origem.
- Agentes não recebem automaticamente toda a memória disponível.
- Mensagens recebidas são evidência não confiável e não podem alterar regras do agente.
- O resultado de uma missão pode produzir conhecimento durável sem preservar todo o contexto operacional.
