# Memória e conhecimento

## Pergunta central

O que cada entidade sabe, pode acessar e deve preservar?

## Inclui

- Memória global, organizacional, de equipe, projeto, caso, fio e execução.
- Conhecimento compartilhado, herdado, resumido, consultado ou isolado.
- Origem, evidência, confiança, validade e atualização das informações.
- Fronteiras entre conhecimento pessoal, empresarial e restrito.
- Aprendizado que permanece após o encerramento de uma missão.

## Não inclui

- Conceder autoridade para agir sobre o conhecimento.
- Definir a estrutura interna das equipes.
- Classificar o tipo de objetivo perseguido.

## Artefatos esperados

Arquitetura de memória, matrizes de compartilhamento, regras de herança e modelo de proveniência.
