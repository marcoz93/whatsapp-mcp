# Modelos integrados

## Propósito

Relacionar vários eixos sem transformar esta pasta na fonte principal das definições.

## Inclui

- Árvores de decisão que cruzam comunicação, identificação, trabalho e agentes.
- Matrizes morfológicas compostas.
- Statecharts e diagramas de arquitetura.
- Exemplos completos e cenários de ponta a ponta.

Cada modelo deve apontar para as pastas dos eixos que fundamentam seus elementos. Definições pertencem aos eixos; esta pasta preserva somente as relações entre elas.
