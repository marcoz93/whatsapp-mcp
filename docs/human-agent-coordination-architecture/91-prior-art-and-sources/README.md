# Trabalhos anteriores e fontes

## Propósito

Registrar formalizações existentes antes de inventar novos conceitos.

## Para cada fonte

- Identificar autores, data e referência primária.
- Resumir o problema tratado e os conceitos formalizados.
- Relacionar a fonte aos eixos deste corpus.
- Registrar o que pode ser reutilizado.
- Registrar pressupostos, limitações e problemas deixados em aberto.

## Fontes iniciais

Gaia, Extended Gaia, MOISE+, BDI, CMMN, BPMN, DMN, conversas para ação, teoria da coordenação e compromissos em sistemas multiagentes.

## Notas separadas já abertas

- [The Architecture of Complexity](architecture-of-complexity/): hierarquia, formas intermediárias estáveis, quase decomponibilidade e consequências para o design time.
- [Gaia](gaia/): modelo organizacional, relação com os eixos e limites.
- [A Conceptual Analysis of Commitments in Multiagent Systems](commitments-in-multiagent-systems/): referência de Singh e distinção inicial entre compromissos psicológicos e sociais.

Uma nota de fonte descreve a proposta de seus autores. As definições deste projeto continuam pertencendo aos eixos correspondentes.
