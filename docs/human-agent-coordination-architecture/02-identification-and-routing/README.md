# Identificação e roteamento

## Pergunta central

A que assunto, fio, objetivo ou contexto um acontecimento pertence?

## Inclui

- Separação de assuntos intercalados na mesma conversa.
- Identificação de fios semânticos.
- Vínculo com caso, projeto, processo ou objetivo existente.
- Criação, reabertura, divisão e união de fios.
- Ambiguidade, confiança, alternativas e confirmação humana.
- Responsabilidades do router.

## Não inclui

- Distribuir tarefas entre agentes ou humanos.
- Definir o ciclo de vida completo do trabalho.
- Definir permissões de execução.

## Artefatos esperados

Árvores de identificação, regras de roteamento, modelo de confiança e casos ambíguos.
