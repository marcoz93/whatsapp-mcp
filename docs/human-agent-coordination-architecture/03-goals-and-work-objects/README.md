# Objetivos e objetos de trabalho

## Pergunta central

O que queremos alcançar e que tipo de trabalho é este?

## Inclui

- Objetivos de criação, manutenção, reparo, melhoria, decisão e prevenção.
- Processos, projetos, casos, programas, rotinas e tarefas.
- Critérios de sucesso, término, abandono e reabertura.
- Decomposição em objetivos e subobjetivos.
- Dependências lógicas entre objetos de trabalho.

## Não inclui

- Escolher o agente ou humano responsável.
- Definir a estrutura organizacional.
- Definir como uma mensagem é interpretada.

## Artefatos esperados

Taxonomia de objetivos, matriz dos objetos de trabalho e relações entre processo, projeto, caso, programa, rotina e tarefa.
