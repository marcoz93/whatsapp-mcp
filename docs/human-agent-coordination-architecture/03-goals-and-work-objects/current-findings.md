# Descobertas atuais: objetivos e objetos de trabalho

## Unidade central

A unidade organizadora não é a mensagem, a conversa, o contato ou o ticket. É o objetivo em andamento.

Comunicações são acontecimentos que podem alterar o estado desse objetivo.

## Tipos de objetivo já identificados

| Tipo | Transformação desejada | Exemplo |
|---|---|---|
| Criar | Algo passa a existir | Organizar uma festa |
| Reparar | Funcionamento é restaurado | Consertar o carro |
| Manter | Um estado adequado continua | Suporte aos clientes |
| Melhorar | Desempenho ou qualidade aumenta | Reduzir reclamações |
| Adquirir | Um recurso passa a estar disponível | Comprar equipamento |
| Decidir | Alternativas se tornam uma escolha | Selecionar fornecedor |
| Compreender | Incerteza se torna explicação suficiente | Encontrar causa raiz |
| Prevenir | Um risco é controlado | Renovar seguro |
| Cumprir | Uma obrigação é satisfeita | Entregar documento |
| Relacionar | Uma relação é preservada ou desenvolvida | Acompanhar familiares |
| Coordenar | Ações dispersas tornam-se alinhadas | Organizar viagem |
| Explorar | Uma possibilidade torna-se objetivo formulado | Pesquisar uma ideia |

Um objetivo pode combinar vários tipos. Consertar o carro pode envolver compreender, decidir, adquirir, coordenar e reparar.

## Objetos de trabalho

| Objeto | Natureza provisória |
|---|---|
| Processo | Caminho repetível e razoavelmente conhecido |
| Projeto | Resultado específico com começo e término |
| Caso | Situação que evolui conforme chegam informações |
| Programa | Responsabilidade contínua que gera trabalhos subordinados |
| Rotina | Trabalho que reaparece em ciclos |
| Tarefa | Unidade concreta de ação |
| Fio | Continuidade semântica pela qual um assunto é acompanhado |

## Características de um objetivo

- Estado desejado e motivo.
- Grau de clareza.
- Critérios de sucesso ou aceitação.
- Restrições de prazo, custo, qualidade e risco.
- Dependências de pessoas, informação, recursos, aprovação ou outros objetivos.
- Forma de decomposição: ação, sequência, paralelo, árvore condicional ou rede.
- Caminho conhecido, adaptativo ou exploratório.
- Condições de encerramento, cancelamento e reabertura.

## Estrutura composta

```text
área ou programa
└── missão ou projeto
    └── caso
        └── tarefa
```

Essa hierarquia é flexível: nem toda situação precisa usar todos os níveis.
